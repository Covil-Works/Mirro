# Limitar altura maxima do menu de contexto de arquivos

## Description

Ao clicar com o botao direito sobre um arquivo, o menu de contexto se estende excessivamente para baixo. Os itens e opcoes estao corretos, mas o menu precisa ter restricao de altura maxima (max-height) e overflow/rolagem adequada para evitar que fique excessivamente comprido.
